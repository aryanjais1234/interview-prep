    BEGINNER

    Fundamentals

    What Spring AI is, how to set it up, and the core vocabulary — models, prompts, tokens, embeddings.

    01

    What is Spring AI?

    Spring AI is just another Spring project, like Spring Data or Spring Security. When your Spring Boot application needs to talk to an AI model, you add Spring AI and it gives you a clean Java API to do that.

    Underneath it is still making REST calls to the provider, but you never write those calls yourself. You work with normal Spring beans and methods.

    Say this in the interview

    "Spring AI is an abstraction layer between my application and any AI model provider. It gives me a Fluent Java API, and it handles the HTTP calls, JSON building and response parsing for me."

    02

    Why use Spring AI instead of calling the provider's REST API directly?

    You can call the API directly with RestTemplate. It works for a hello-world demo. But you lose everything that makes a real feature manageable.

    • Provider switching — change from OpenAI to Ollama by changing a dependency and a property. Your business code does not change at all.
    • Prompt management — templates, external files, dynamic variables, roles.
    • Structured output — get a Java object back instead of a String you have to parse.
    • Chat memory, RAG, streaming, tool calling — all built in.

    Writing all of that yourself is a lot of code, and it is code that has nothing to do with your product.

    03

    What is an LLM?

    LLM means Large Language Model. It is a model trained on a huge amount of text, and its main job is to predict the next piece of text. That is why it can answer questions, write code and summarise documents.

    GPT, Claude, Llama, DeepSeek and Mistral are all LLMs. Spring AI can talk to any of them.

    Follow-up they may ask

    "Is ChatGPT the model?" No. ChatGPT is a website that wraps the model. It adds memory, web search, file upload and formatting. The model itself does none of that.

    04

    Which providers does Spring AI support?

    Almost all the popular ones: OpenAI, Azure OpenAI, Anthropic, Google Vertex AI, Amazon Bedrock, Mistral, DeepSeek, Hugging Face, Groq and Ollama for local models.

    You pick one by adding its starter dependency. The API you write against stays the same.

    05

    Which dependency do you add to use OpenAI?

    One starter. It brings in Spring AI plus the OpenAI implementation.

    In Spring Initializr it is listed simply as OpenAI. Be careful not to pick Azure OpenAI by mistake — that one is only for Azure.

    06

    How do you configure the OpenAI API key?

    The ${OPENAI_API_KEY} part reads an environment variable. In IntelliJ you set it under Edit Configurations → Modify options → Environment variables.

    07

    Why should you never hardcode the API key?

    Because it ends up in Git. Once a key is pushed to a repository it is compromised, even if you delete it later, because it stays in the commit history. People have run up very large bills this way.

    Use an environment variable locally, and a proper secret manager (Vault, AWS Secrets Manager, Kubernetes secrets) in production.

    08

    What is ChatClient?

    ChatClient is the main class you use as a developer. It is a helper that makes talking to the model easy. You give it a prompt, call it, and get the content back.

    It hides the HTTP request, the JSON format, the token handling and the response parsing.

    09

    Why can you not inject ChatClient directly?

    Because Spring AI does not create a ChatClient bean. It creates a ChatClient.Builder bean. If you try to inject ChatClient the app fails at startup with "a bean of type ChatClient could not be found".

    The reason is that different parts of your app usually want different settings — different system prompts, different advisors, different models. So Spring gives you the builder and lets you decide.

    Very common interview question

    This exact point comes up a lot. Remember: inject the Builder, call build().

    12

    What do prompt(), call() and content() each do?

    MethodWhat it does
    prompt()Builds the request. You pass the text, or a Prompt object, or nothing and then chain .system() and .user().
    call()Actually sends the request and waits for the full answer.
    content()Pulls the plain text out of the response.

    Instead of content() you can use chatResponse() for the full response with metadata, or entity(MyClass.class) for a Java object.

    13

    What is a Fluent API and where does Spring AI use it?

    A Fluent API is one where each method returns something you can call the next method on, so the code reads like a sentence. Spring AI uses it everywhere in ChatClient.

    The benefit is readability and that the IDE guides you — after .call() it only offers the methods that make sense at that point.

    14

    What is Ollama and why would you use it?

    Ollama is software that runs open-source models on your own computer. The main reason to use it is that it is free — there is no API bill because nothing leaves your machine.

    The second reason is privacy. If you cannot send customer data to a third party, a local model solves that.

    The trade-off is performance. Models are several GB and need a decent machine.

    15

    How do you connect Spring AI to Ollama?

    Common mistake

    Spring AI's default Ollama model is mistral. If you did not download mistral you get a "model not found" error. Always set the model property to what you actually pulled.

    16

    How much of your code changes when you switch from OpenAI to Ollama?

    None of the Java code changes. Only the dependency and the properties. The controller, the service, the ChatClient usage — all identical.

    That is the whole point of the abstraction, and it is a great answer to give because it shows you understand why Spring AI exists, not just how to use it.

    17

    What is a "model" in AI terms?

    A model is a program that was trained on a lot of data and can now generate something new — text, images, audio, or embeddings.

    TypeExampleDoes what
    Chat / LLMgpt-4o-miniText in, text out
    Embeddingtext-embedding-3-smallText in, numbers out
    ImageDALL·EText in, image out
    AudioWhisperAudio in, text out

    Spring AI supports all four types.

    18

    What is a prompt?

    A prompt is everything you send to the model. It is not just the user's question — it is a set of messages, plus options like model name and temperature.

    So the formula is: prompt = messages + options.

    19

    What is a token?

    A token is the smallest piece of text the model understands. Before anything happens, your text is split into tokens, each token gets an id, and those ids are what the model actually processes.

    A token can be a whole word, part of a word, or punctuation. For example "unbelievable" might become one token, or three (un / believe / able), depending on the tokenizer.

    Rule of thumb worth remembering

    About 4 characters = 1 token in English. Roughly 75 words = 100 tokens. "what is java?" is 4 tokens.

    20

    Why do tokens matter so much?

    Two reasons, and interviewers usually want both.

    1. Cost. You are billed per token, separately for input and output. More text means a bigger bill. Cost is directly proportional to tokens.
    2. Limit. Every model has a context window — the maximum tokens it can handle in one request. You physically cannot send more than that.

    This is exactly why RAG exists. Instead of sending a whole document, you send only the relevant few paragraphs.

    21

    What is a context window?

    The maximum number of tokens a model can process in a single request — your prompt, the chat history, any retrieved documents, and the answer, all together.

    Newer models have very large windows (hundreds of thousands of tokens), older ones were much smaller. If you go over it, the request fails.

    Practical point

    A big context window does not mean you should fill it. You still pay for every token. Sending 400,000 tokens of context on every request is a good way to lose your job.

    22

    What is temperature?

    Temperature controls how random or creative the answer is.

    • Low (0.0 – 0.3) — predictable and factual. Use for classification, data extraction, anything you want repeatable.
    • High (0.8 – 1.0) — creative and varied. Use for marketing copy, brainstorming, story writing.

    Spring AI's default is 0.7, which is worth knowing because some models reject it.

    23

    What does max-tokens control?

    It limits how long the answer can be. It does not limit your input.

    It is useful for controlling cost and for stopping the model from rambling. The downside is that if the model needs more room, the answer just gets cut off in the middle.

    24

    What are the message roles?

    RoleWho writes itPurpose
    userThe end userThe actual question
    systemYou, the developerRules and behaviour
    assistantThe modelEvery answer you receive
    toolTool callingResult of a function call

    Not every model supports all four. GPT supports all of them; some others only support user and system, so check before you rely on it.

    25

    What is a system message and why is it important?

    The system message sets the rules and personality. It is how you control the model's behaviour without changing the user's question.

    In a real product almost all of your prompt engineering lives in the system message.

    26

    What is an assistant message?

    It is the message the model sends back. Every answer you get from the LLM has the role ASSISTANT.

    It matters when you use chat memory, because the history that gets replayed is a mix of user messages and assistant messages — that is how the model knows what it already said.

    28

    You set a new model and got "temperature does not support 0.7". Why?

    Spring AI sets a default temperature of 0.7 for you. Some newer models only accept one fixed temperature value, so they reject it.

    Fix it by setting a supported value, or by removing the property so the model uses its own default.

    Related error

    "Invalid model ID" is almost always a typo or a trailing space in the property value. Check it character by character.

    29

    What does Spring Boot auto-configuration do for Spring AI?

    When the starter is on the classpath, Spring Boot loads a configuration class (for OpenAI it is OpenAiChatAutoConfiguration). That class reads your properties and creates the beans — the ChatModel, the ChatClient.Builder, the embedding model.

    This is also why the app fails at startup if the API key is missing: auto-configuration runs before your code does, and it cannot build the beans without a key.

    30

    ChatModel is an interface that represents one specific provider. Each provider ships its own implementation.

    ProviderImplementation class

    OllamaOllamaChatModel
    AnthropicAnthropicChatModel

    You normally never touch it. ChatClient uses it internally.

    31

    What is the difference between ChatClient and ChatModel?

    ChatClientChatModel
    LevelHigher abstractionLower abstraction
    Made forDevelopers — youInternal use

    The flow is: Controller → ChatClient → ChatModel → the provider's API.

    You only touch ChatModel directly when you need multiple providers in one app and have to build clients yourself.

    32

    What are embeddings?

    An embedding turns text into a list of numbers (a vector) that captures its meaning, not just its words.

    The useful property is that similar meanings produce similar numbers. "King" and "queen" end up close together; "king" and "car" end up far apart. That is what makes semantic search possible.

    33

    What is a vector?

    In this context, a vector is simply an array of numbers that represents a piece of information. Text, images and audio can all be turned into vectors.

    A useful mental picture: imagine plotting every sentence as a point in space. Related sentences land near each other. Searching then means "find the nearest points", which is done with maths like cosine similarity.

    34

    What is a vector database and how is it different from MySQL?

    Normal databaseVector database
    StoresRows and columnsVectors (embeddings)
    You search byExact match, LIKE, rangesSimilarity — "closest meaning"
    Question it answers"Where name = 'John'""What is similar to this?"

    Spring AI supports PgVector, MariaDB, Qdrant, Pinecone, Redis, Chroma, Neo4j and more.

    Good extra point

    PgVector is a PostgreSQL extension, so you can use one database for both your normal tables and your embeddings. One less system to run and back up.

    35

    What does it mean that an LLM is stateless?

    It means the model remembers nothing between requests. Each call is completely fresh.

    ChatGPT feels like it remembers because the application stores the conversation and re-sends it every time. Spring AI gives you the same thing through chat memory.

    INTERMEDIATE

    Building real features

    Structured output, prompt templates, advisors, streaming, chat memory and multiple providers — the things you actually write in a project.

    36

    How do you use two different AI providers in one project?

    Three steps.

    1. Add both dependencies. 2. Turn off the auto-created builder. 3. Create one named ChatClient bean per provider.

    Note ChatClient.builder(model) — this is the static factory that takes a ChatModel. That is the one place you use ChatModel directly.

    37

    What does spring.ai.chat.client.enabled=false do, and why is it needed?

    It stops Spring AI from auto-creating the ChatClient.Builder bean.

    With two providers on the classpath you get two ChatModel beans but Spring only knows how to build one default builder, so it becomes ambiguous and the app fails to start. Turning it off makes creating clients your responsibility, which is what you want anyway.

    38

    How do you inject the right client when you have two of the same type?

    With @Qualifier, and the name must match the bean name exactly.

    Without the qualifier you get "expected single matching bean but found 2" at startup.

    39

    Why would you use two providers in one application?

    • Task specialisation — a cheap model for classification, an expensive one for reasoning.
    • Fallback — if OpenAI is down, switch to a local Ollama model so the feature degrades instead of dying.
    • Cost control — route free-tier users to a cheaper model.
    • A/B testing — compare answer quality before committing.
    40

    What is structured output and why do you need it?

    By default the model returns plain text. Even when it looks like JSON, it is a String — you can see the quotes around it.

    Inside a program that is a problem. You want a Java object you can validate, store and return from an API. Structured output makes Spring AI convert the answer into a real object for you.

    43

    How does structured output actually work behind the scenes?

    Spring AI does three things:

    1. Builds a JSON schema from your class and appends it to your prompt as extra instructions describing the exact fields and types it wants.
    2. Validates the JSON that comes back.
    3. Converts it into your object — and retries if the JSON was malformed.

    You can see the injected instructions yourself by switching on the logging advisor.

    Nice detail to mention

    Field descriptions in your class are not just comments — they are sent to the model. Writing clear descriptions genuinely improves the answers.

    What is ChatResponse and when do you use it?

    content() gives you only the text. chatResponse() gives you the whole response object including metadata — token usage, model name, rate limits, finish reason.

    46

    What are chat options?

    Settings that control how the answer is generated — model, temperature, max tokens, frequency penalty and so on. ChatOptions is an interface; the implementation is provider specific (OpenAiChatOptions, OllamaChatOptions).

    47

    What are the three levels at which you can set options?

    1. Global — in properties, applies everywhere.

    2. Per client — the usual choice.

    3. Per request — when one call needs something different.

    48

    What does defaultSystem() do?

    It sets a system message once, on the client, so every call through that client gets it — you do not repeat it in ten places.

    There are matching methods for the rest: defaultOptions(), defaultAdvisors(), defaultUser(), defaultTools().

    49

    What is a prompt template and why not just concatenate strings?

    A prompt template is a prompt with placeholders that you fill at runtime, like a prepared statement in JDBC.

    String concatenation works for one variable. With three or four it becomes unreadable and you start making mistakes with spaces and punctuation. Templates keep the prompt readable and reusable.

    Common error

    "Attribute concept is not defined" means the placeholder name and the param() key do not match. They must be spelled identically.

    50

    Show the step-by-step PromptTemplate approach.

    Four steps: build the template, render it, wrap it in a Prompt, call it.

    Use this when you need to build a prompt in stages. For normal cases the Fluent API is shorter.

    51

    What is the difference between render() and createMessage()?

    MethodReturnsUse when
    render()A StringYou just need the text
    createMessage()A Message objectYou are combining several role-based messages into one Prompt

    A Prompt cannot take multiple raw Strings, so if you want a system message and a user message together you need createMessage().

    52

    Is there a UserPromptTemplate?

    No, and this catches people out. There is SystemPromptTemplate, AssistantPromptTemplate and FunctionPromptTemplate, but no user one.

    The plain PromptTemplate is the user template.

    53

    How do you keep prompts in files instead of in Java code?

    Put them in src/main/resources as .st files and load them with @Value.

    The benefit is that a non-developer can improve the prompt, and you can change it without recompiling.

    54

    What is the classic import mistake when loading prompt files?

    The IDE auto-imports jakarta.annotation.Resource. You need org.springframework.core.io.Resource.

    Second gotcha

    Use @Value("classpath:file.st") with no dollar sign. The ${...} syntax is for properties, not for classpath files.

    55

    What is a template renderer?

    The component that actually replaces the placeholders. The default is StTemplateRenderer, which uses the StringTemplate library and curly braces { }.

    You can write your own if you need different delimiters — for example if your prompts contain JSON, where curly braces would clash.

    56

    What are advisors in Spring AI?

    Advisors are interceptors. They sit between the ChatClient and the model, and they run before the request goes out and after the response comes back.

    They are how Spring AI adds cross-cutting features — logging, chat memory, RAG, safety checks — without you changing your business code.

    What does SafeGuardAdvisor do?

    It blocks the request before it reaches the model if the input contains any word from a list you give it. The user gets a polite refusal instead.

    It saves money too — a blocked request costs nothing because no API call happens.

    The mistake to avoid

    If you also implement StreamAdvisor, do not return null from adviseStream. You must forward with chain.nextStream(request) or streaming silently returns nothing.

    63

    How is advisor order decided?

    Each advisor has a getOrder() value. Higher order runs earlier on the way out. On the way back they unwind in reverse, like a stack.

    If two advisors have the same order there is no guarantee which runs first, so give them distinct values when it matters.

    64

    What is streaming and why use it?

    Without streaming, the user waits for the whole answer before seeing anything. With streaming you send each chunk as the model produces it — that is the ChatGPT typing effect.

    The user starts reading in under a second instead of waiting ten. It does not make the total time shorter, it makes the wait feel shorter, and people are much less likely to leave.

    What is chat memory and why do you need it?

    Because the LLM is stateless, chat memory stores the conversation and re-sends it with each new request. That is the only way the model can know what you said before.

    Spring AI does this automatically through an advisor — you do not build the message list yourself.

    What is MessageWindowChatMemory?

    The default ChatMemory implementation. It keeps a rolling window of the last 20 messages by default. When new messages arrive the oldest ones are dropped.

    71

    What is InMemoryChatMemoryRepository and what is its limitation?

    The default repository. It stores messages in a ConcurrentHashMap where the key is the conversation id and the value is the list of messages.

    The limitation is obvious: restart the application and everything is gone. It is also not shared between instances, so with two pods a user could get different history depending on which one served the request.

    72

    How do you store chat memory in a database?

    Add the JDBC dependency and set one property. Spring AI auto-configures the repository and MessageWindowChatMemory starts using it automatically.

    Supported: PostgreSQL, MySQL, MariaDB, SQL Server, HSQLDB. Spring creates a spring_ai_chat_memory table with conversation id, content, type and timestamp.

    ADVANCED

    RAG, tools and production

    Retrieval Augmented Generation, the ETL pipeline, tool calling, audio, and the questions about cost and scale that senior interviewers actually care about.

    73

    What is RAG and why is it needed?

    RAG means Retrieval Augmented Generation. The model knows nothing about your private data, so before asking it a question you fetch the relevant pieces of your own data and include them in the prompt.

    LetterStep
    RetrievalSearch your database for the most relevant chunks
    AugmentedAdd those chunks to the prompt as context
    GenerationThe model answers using that context

    The alternative — pasting your whole document into every prompt — burns tokens and eventually breaks the context window.

    74

    Walk me through the complete RAG flow.

    The key insight is step 3: you send only the 3 to 5 most relevant paragraphs, not the whole document.

    75

    What problems does RAG solve?

    • Private data — the model was never trained on your company's documents.
    • Training cutoff — it does not know anything recent.
    • Context limit — you cannot paste a whole book into a prompt.
    • Hallucination — grounding the answer in real retrieved text makes it far more accurate, and you can cite the source.

    78

    How do you keep one customer's data separate from another's in a shared vector store?

    Two parts. When saving, tag every chunk with the tenant. When searching, filter on it.

    Why this matters

    The filter must be part of the query, not a check you do afterwards on the results. If you forget it, one customer sees another customer's documents — which is the kind of bug that ends a product.

    What is QuestionAnswerAdvisor?

    It does everything from the previous question automatically — the search, the context assembly and the strict instructions.

    81

    When would you write RAG manually instead of using the advisor?

    • You need a custom prompt format the advisor does not produce.
    • You want to log or post-process the retrieved chunks before sending them.
    • You need to combine results from a vector store and a normal SQL query.
    • You want to show the user which sources were used.

    For everything else the advisor is less code and less to get wrong.

    82

    What is RetrievalAugmentationAdvisor and how is it different?

    QuestionAnswerAdvisor does simple RAG: one search, one prompt. RetrievalAugmentationAdvisor implements modular RAG, where the flow is broken into phases you can plug into.

    83

    What are query transformers?

    They improve the user's question before you search with it.

    TransformerDoes what
    RewriteQueryTransformerTurns a messy question into a clean one. "I'm studying ML, what is an LLM?" becomes "Large Language Model definition".
    TranslationQueryTransformerTranslates the question into the language your documents are in.
    CompressionQueryTransformerCompresses a long conversation into one standalone question.
    Important detail

    Every transformer calls the LLM itself, so each one costs tokens and adds latency. Do not stack four of them without a reason.

    Better recall, but three times the searches — and the expansion itself is an extra LLM call.

    89

    What is TokenTextSplitter and why does chunk size matter so much?

    Chunk size is the single biggest quality lever in RAG:

    • Too small — an idea gets split in half and neither chunk makes sense on its own.
    • Too large — one chunk covers two unrelated topics, so the search returns it for questions it does not really answer.

    Tune it against your own documents. It moves accuracy more than any prompt change.

    90

    What is a Document in Spring AI?

    The unit that flows through the whole pipeline. It holds content, metadata, and optionally media references.

    The metadata is what you filter on later, so decide early what you will need.

    91

    What is tool calling and what problem does it solve?

    An LLM only knows its training data. It cannot tell you today's date, today's weather, or what is in your database. Tool calling lets it use your Java methods to get that information or to take an action.

    Two kinds of tool: information tools (get the weather, query the DB) and action tools (send an email, create a ticket).

    92

    Write a tool.

    The descriptions are not comments

    The model reads description to decide whether to call the tool and what to pass. Vague descriptions mean the tool gets called at the wrong time or with the wrong arguments.

    93

    Who actually executes the tool — the LLM or your application?

    Your application does. The model never runs code. This is a favourite interview question.

    So there are normally two round trips to the model for one tool call.

    94

    What does returnDirect do?

    By default the tool result goes back to the model so it can phrase a nice answer. With returnDirect = true the raw result is returned straight to the user and step 5 is skipped.

    Use it when the result is already structured data your UI can render. It saves one LLM call, so it is faster and cheaper.

    How does the model handle a question that needs two tool calls?

    It calls them both, on its own. If you ask "compare the weather in Delhi and Mumbai", the logs show getWeather called twice, then the model writes the comparison itself.

    You did not write any comparison logic. That is the part that makes tool calling feel different from a normal API.

    How would you design an AI feature so it does not fall over under load?

    The core problem is that an AI call takes seconds, not milliseconds, and the provider rate-limits you. So do not do it inside the HTTP request.

    • Queue the work so bursts become queue depth instead of errors.
    • Fix the consumer concurrency — that number is your LLM rate limit.
    • Cache answers in Redis. Repeated questions are common and cost nothing to serve.
    • Retry with backoff, then a dead letter queue so one bad message does not block others.
    • Circuit breaker on the model call so you stop hammering a provider that is down.
